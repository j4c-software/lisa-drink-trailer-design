# Lisa Drink Trailer Design

Authoritative concept-design record for the Lisa mobile cocktail-bar trailer conversion.

Start with [`00-PROJECT-BOOTSTRAP.md`](00-PROJECT-BOOTSTRAP.md). It defines the required reading order, authority hierarchy and change-control process.

## Current state

- Three approved concept options using one conservative Circle J two-horse trailer basis
- Three authoritative plan views and twelve authoritative interior elevations
- Locked 24-page US Letter landscape presentation specification
- Controlled photographic-rendering briefs and visual QA workflow
- Draft vector concept drawings: [three plans and twelve elevations](drawings/README.md)
- Concept development only: the donor trailer has not been acquired or measured
- No fabrication, procurement or permit release

## Authority

This repository is the sole authoritative project record. Chat discussions, generated images and exported documents are not authoritative unless their decisions are incorporated and committed here.
