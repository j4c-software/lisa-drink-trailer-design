# Lisa Drink Trailer — Render Brief Matrix

**Revision:** 1.0 — September 7, 2026  
**Status:** CANONICAL IMAGE-BY-IMAGE CONTROL

This matrix preserves the approved concept for every photographic rendering. It does not replace the Master, Option, Presentation or Rendering-Control files. Each image brief is assembled from all of them, with the applicable authoritative plan/elevations in the Option file controlling geometry.

## Universal assembly rule

For every candidate, combine in this order:

1. Presentation-page purpose
2. Common trailer or interior scene brief
3. Applicable Option A/B/C overlay
4. Applicable approved plan and elevations
5. Camera/view definition
6. Operating or travel state
7. Required people, equipment, setting and labels
8. Common prohibitions and QA checklist

Any conflict stops production. The renderer may not solve a conflict by inventing, moving, substituting or omitting elements.
